方法正文的阅读对象是规划者。规划者基于它生成或修订具体 `[tracking]` Execution Trace（三件套落在 [docs/traces/](../traces/README.md)）；产品负责人批准明确的 Trace 版本后，编排者只执行该 Trace 及其中绑定的来源。Trace 缺项时必须退回规划者修订，编排者不得从方法正文临场补合同。

产品合同、技术设计、验证与门禁仍按本仓库 `docs/` 的对应文件读取；只有长期执行方法正文维护在套件里。
