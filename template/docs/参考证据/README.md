# 长期参考证据

> 出处：lingxi [docs/参考证据/README.md](https://github.com/Moshuiwang/lingxi/blob/caa845d77fbd2d6381de304dc6047498aa84c782/docs/参考证据/README.md)；验证：全仓（9 份证据入库、3 份一次性执行卡按此规则退场）；分档 G2（只保留准入规则，证据列表留空）。

这里仅保存可重复使用、已脱离单次讨论的脱敏事实与验证方法，例如外部平台已验证的限制、复验步骤或公开规范摘录。

进行中的调研、假设、待决策方案和一次性测试记录必须留在 GitHub Issue / PR。证据若影响用户预期，必须先把结论提炼到[当前能力](../当前能力.md)、[产品合同](../产品合同.md)或一份[长期决策记录](../决策记录/README.md)；证据文件本身不定义产品规则。

## 准入规则

- 进：可重复使用的外部平台事实、复验步骤、脱敏后的验证结果、公开规范摘录、门禁的形成记录（只追溯原因，不定义当前规则或当前通过状态）。
- 不进：一次性执行卡与验收记录（留 Issue / PR；已入库的退场时在本文留一条指向 git 历史固定提交的入口即可）、凭据、真实业务数据、未脱敏的截图或日志。
- 每份证据开头写明来源 Issue / PR、验证日期与范围边界；结论被替代时更新原文或标注「已替代」，与之冲突的旧证据写明以谁为准。
