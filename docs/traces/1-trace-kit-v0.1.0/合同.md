## 4. 验收标准

- **自回灌**：template 中每个有 lingxi 对应物的文件与 lingxi `main@caa845d` diff，lingxi 侧差异行必须命中 G3 关键词表或为占位行；未命中者逐条人工复核，结论写进 `验收.md`。
- **空项目冒烟**：本机临时目录从 template 起空项目 → `init.sh` → `scripts/dev/check.sh` 三层 + 全部 `scripts/ci/*` 通过 → `claude plugin validate --strict` 通过 → 用插件 skill 走 kickoff → 三件套落盘 → 任务表勾选一条。
- **套件自检 CI**：本仓 `kit-selfcheck` 工作流固化冒烟中不依赖 Claude 会话的部分（空项目生成 + 检查全绿 + 禁词扫描）。
- **独立审查**：一名只读审核者（Fable 5.1 xhigh）对冻结候选做一次批量审查（出处链接真实性、分档正确性、禁词、可运行性、文档「是什么 / 怎么用 / 换什么」），统一修复包后同一审核者定向复核一次。
- **证据等级要求**：脚本类 ≥ 全局 3（本机测试通过）且 kit CI 通过为 4；工作流 YAML 只到 3；宣称交付前未验证层级必须列明。
- **证据只认仓库 / GitHub 留痕**：审查结论、冒烟输出摘要、失败事件当天落 Issue #1 评论或 PR；任务表随执行 commit 勾选（第一恢复点）。
